One-time set-up (about 15 minutes; the website's Google Analytics already exists)

  1. Go to console.cloud.google.com, signed in with the Google account that owns the analytics. Create a project called "Neverlank analytics".
  2. In that project open APIs and Services, then Library, search for "Google Analytics Data API" and press Enable.
  3. Open IAM and Admin, then Service Accounts, press Create service account, name it "neverlank-app", and finish (no roles needed).
  4. Open that service account, choose Keys, Add key, Create new key, JSON. A file downloads. Keep it private: it is a password.
  5. In analytics.google.com go to Admin, Property access management, press +, add the service account's email (it looks like neverlank-app@...iam.gserviceaccount.com) and give it the Viewer role.
  6. In Analytics, Admin, Property details, copy the Property ID (a number, not the G- code).
  7. On Render, open the app's Environment page and add GA4_PROPERTY_ID (that number) and GA4_SERVICE_ACCOUNT_JSON (open the downloaded file in Notepad and paste all of it). Save, wait for the redeploy, then press "Test the connection" here.

The app only reads (Viewer). Only visitors who pressed Accept on the website's cookie banner are counted by Google Analytics, so website visits are a minimum. Never paste the key into a chat or an email.
