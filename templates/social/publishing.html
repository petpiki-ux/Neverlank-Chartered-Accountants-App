How to connect Make (about 15 minutes)

  1. In Make, create a scenario that starts with Webhooks > Custom webhook. Copy the web address it gives you into SOCIAL_WEBHOOK_URL on Render.
  2. Choose a long random text and put it in SOCIAL_WEBHOOK_SECRET on Render. Every request carries it in the header X-Neverlank-Token; add a filter in Make that stops the scenario if the header is different.
  3. Add a Router on the field platform (linkedin, x, facebook, instagram) and, on each branch, the platform's own module (for example LinkedIn > Create a post). Map text, and for pictures use the images list: each has a url that Make can fetch.
  4. Set PUBLIC_BASE_URL to the address of this app, then press “Send a test” above. The test carries event = test: stop the scenario on that so nothing is posted.
  5. Optional: have the last Make step call the field callback_url with post_id, platform and url (the live address), or ok=false and error, so the app can show it. Buffer, Zapier and n8n work the same way.
  6. Timer: a free service such as cron-job.org can call {{ base }}/social/cron?token=YOUR_SOCIAL_CRON_TOKEN every 5 minutes. Without it, due posts go out whenever someone opens the Social pages.

Rules: only approved posts with no errors in the checks are sent; a post whose time passed more than {{ late_hours }} hours ago is held, not sent; a failed send is tried again up to {{ tries }} times.
