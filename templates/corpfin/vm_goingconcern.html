Going-concern and development value

{% if not locked %}{% endif %}

For a business that is moving into production. Component valuations value each asset on the evidence supplied; this section adds what they do not carry — the value of the production plan as a whole, synergies between the assets, and development options — and takes off the capex still to be spent and ramp-up costs. Every item is multiplied by its probability of being achieved, so a pre-production plan is not valued as if it were certain. Amounts are present values at the valuation date.

Avoid double counting. If a component was valued by a DCF of its own production, that value is already in the sum of the parts. Add only what is not in it, or enter the overlap as “Less: value already inside the component values”.
