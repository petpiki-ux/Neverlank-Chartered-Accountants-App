1. Opening balances as at {{ as_at_label }}

The closing position of the year before, asset by asset: what each asset cost, the depreciation built up to {{ as_at_label }}, and its tax value brought forward (the closing tax value on last year's capital allowance schedule). Enter it once; the year's movements below start from here. An asset with no tax value brought forward has its tax value rebuilt from its cost and date acquired.

Import the client's asset register

Upload the register as an Excel (.xlsx) or CSV file in whatever layout the client has it. The app finds the header row, matches the columns (code, description, class, date acquired, cost, accumulated depreciation, net book value, tax value, date sold, proceeds, ...), takes class headings and skips totals, and sorts each asset into an opening balance, an addition or a disposal. You see exactly what it picked up before anything is saved.
