Add a new Standard Chart account

Can't find the account you need in the Standard Account lists? Add it here and use it straight away. It joins the firm-wide Standard Chart of Accounts and a Partner sees it marked "added from an engagement" to review. You can also give it the firm's own category (for example "Biological assets" or "Staff welfare"): the account still rolls into the IAS 1 line you choose, so the financial statements are not changed; the own category is shown as a finer heading on the trial balance.

Paste accounts from Excel

Copy the rows in Excel and paste them below. Columns, in order: Code, Account name, Current Dr, Current Cr, Prior Dr, Prior Cr (a header row and a missing Code column are fine; blank amounts count as 0). These are added to the accounts already here; an import replaces them. Accounts the client's remembered mappings recognise are mapped automatically.
