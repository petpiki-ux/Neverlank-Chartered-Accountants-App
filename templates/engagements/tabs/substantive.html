{% elif engagement.type == 'Business Intelligence and IT Engagements' %}

Phase 3: IT & cyber assurance procedures

One section per scoped domain: Cyber Security (network defense, penetration testing oversight, incident response, perimeter security), Information Security (data classification, encryption at rest and in transit, DLP, IAM), Information Technology/ICT (IT governance, change management, disaster recovery/BCP, hardware/software lifecycle), and AML/CFT Compliance (transaction monitoring, PEP/sanctions screening tuning, data ingestion integrity, system-generated audit trails). Every procedure carries a Kind - ITGC for a test of the underlying control environment (policy/design review, walkthroughs), or Substantive for a data-driven or technical validation procedure - so the programme reads as the two-column ITGC/Substantive table the methodology calls for. "Generate suggested procedures" seeds each domain with its baseline set, each already tagged. Safe to re-run any time - it only adds what's missing, never duplicates or removes anything.
