Keeping them safe

  • These backups sit on the same disk as the live data. They protect against mistakes, a bad import or a corrupted database - not against losing the disk. Download one regularly (for example every Friday) and keep it in OneDrive.
  • What is in each backup: the database, and every file the app keeps under {{ data_dir }} (uploads, document templates, policy / notice / legislation libraries, ZIMRA files).
  • Not in a backup: the program code (it is in GitHub) and the Render environment variables such as the secret key, email key and API keys - keep a private copy of those.
  • Render also takes its own snapshots of the disk; check the service's Disks page in the Render dashboard.
